## [1.0.0] — 2025-05-03

### 🎉 Initial Release

#### Added
- Universal CLI (`tri`) with 12+ commands
- Smart model router — task classification → optimal model
- 5 provider adapters: Anthropic, OpenAI, Google Gemini, Groq, Ollama
- 10 expert agents: CTO, CEO, Designer, Marketer, Researcher, QA, Security, Writer, Investor, Data Scientist
- Swarm orchestration: parallel, sequential, and debate modes
- Interactive chat REPL (`tri chat`) with streaming
- Startup Factory — 7-section launch kit from a single idea
- Money Mode — personalized AI income roadmap
- Token cost optimizer — analyze and reduce prompt costs
- Code developer tools: review, commit messages, docs, tests, explain
- Benchmark runner — evaluate models on standardized tasks
- Workflow templates — multi-step agent pipelines
- Plugin architecture — extensible with community plugins
- Persistent session memory across conversations
- Daily AI ecosystem discovery (GitHub Action)
- TriAgentOS University — AI learning curriculum
- Streaming support for Anthropic and OpenAI
- Retry logic with exponential backoff
- Model registry with pricing data (9 models)
- GitHub Actions: CI (Node 18/20/22) + daily discovery
- Full documentation: README, ROADMAP, CONTRIBUTING, SECURITY
